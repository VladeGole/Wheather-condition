# 🌤️ Weather Condition App

Welcome to the project repository! This is a simple and clean web application designed to track current weather conditions.

This document is written to be easily understandable for everyone—whether you are a developer, a designer, or just someone interested in seeing what this app does.

<img width="1904" height="954" alt="temperature" src="https://github.com/user-attachments/assets/ef41570b-9c44-42fe-8327-03af59a7e17a" />


## 🎯 What Does This App Do?
This application serves as a clear digital view of the current weather. It allows users to:
* Quickly check live weather conditions.
* View temperature and key climate metrics in a simple and visually appealing format.

---

## 🛠️ How Was It Built?
Behind the clean user interface, the application uses modern web technologies:
* **React** – A popular frontend library used for building interactive user interfaces.
* **TypeScript** – A programming language built on JavaScript that helps keep the code reliable, predictable, and error-free.
* **CSS** – Used for styling, layout, colors, and overall visual design.

## 🚀 How to Run the App Locally

If you would like to run and test this app on your computer, follow these simple steps:

1. **Download the code** from this page (by clicking the green *"Code"* button and selecting *"Download ZIP"*, or by running this command in your terminal):
   ```bash
   git clone https://github.com/VladeGole/Wheather-condition.git
Open your terminal and navigate to the project directory.

Install dependencies (the required packages for the app to run) by typing:

Bash
npm install
Start the application with:

Bash
npm start
Open your web browser (Chrome, Firefox, Edge, etc.) and go to http://localhost:3000 to see the app in action.
